THE CHALLENGE: MEDBUDDY

A voice-friendly medication companion for older adults and care teams.

THE OPPORTUNITY

Older adults with multiple medications face confusion, adherence gaps, and fragmented communication with caregivers and clinicians.

The wedge is a conversational companion that improves medication understanding, structured logging, and care-team handoffs rather than simply sending reminders.

YOUR BUILD

Build an older-adult-friendly medication workflow that:

* Uses a voice-friendly or highly accessible chat interaction for medication review.
* Explains medication purpose, timing, and interaction considerations using grounded reference data and clear limits.
* Captures a structured medication, symptom, or adherence log over time.
* Generates a clinician- or caregiver-reviewable summary.
* Escalates uncertainty or risk instead of making autonomous medical decisions.

Depth area:

Go deep in at least one of the following areas:

* Medication-data grounding
* Voice UX
* Mandarin support
* Caregiver workflows
* Clinician summaries
* Safety escalation
* Longitudinal logging

HOW WE EVALUATE

Working prototype:

This is the main event. Source code is required, and the implementation must run.

Include:

* The exact command, or live URL, that runs the prototype end to end.
* The exact command that runs the tests.

AI Fund will execute both before scheduling a panel.

Build quality:

Rough is fine, and you may use any tools or AI assistants.

A polished prompt, generated document, or thin LLM wrapper is not enough.

Review order:

Reviewers start with the PRD and TDD, then verify the implementation through the prototype and source code.

PRD

Define the first older-adult, caregiver, and clinician workflow.

Explain why medication comprehension and care-team handoffs are the right wedge.

Map the path from the initial workflow to a broader chronic-care product.

TDD

Cover:

* Medication-data grounding
* Voice or chat architecture
* Structured logs
* Summary generation
* Safety boundaries
* Escalation
* Evaluation
* Privacy
* Failure modes
