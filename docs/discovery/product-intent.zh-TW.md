## 已確認的產品意圖

- **預期成果：** 將診間一次性的口頭醫囑，轉化為可以確認、回顧、追溯來源，並在長者同意後與家人分享的資訊。
- **主要使用者：** 35-50 歲、居住在台灣都會區、不與父母同住，但非正式地負責協調父母健康資訊的成年子女。
- **高齡參與者：** 與配偶住在另一個醫療資源充足的台灣城市、生活大致能自理、因慢性病往返醫院與診所，且曾因聽力困難而無法清楚接收或轉述醫囑的父母。
- **為什麼是現在：** 台灣就醫便利，但醫囑、處方與家庭觀察仍然零碎。LINE 訊息、藥袋照片與依靠記憶的轉述，無法建立可信且共享的就醫紀錄。
- **產品切入點：** 聽力相關的醫療溝通失效。聽力困難是第一階段使用者的篩選條件；多模態 accessibility 是設計原則，而不是宣稱解決所有無障礙需求。
- **成功定義：** 長者自願且持續分享就醫資訊；家人能理解並協助，但不接管決策；長者感受到支持、成就與更緊密的家庭關係，而不是被監控。
- **信任與安全：** 清楚區分原始醫囑、政府或專業參考資料、家庭觀察，以及 AI 產生的內容。遇到不確定性時應升級處理，而不是自行補出答案。
- **長期方向：** 從單次看診到家庭的資訊交接，發展為長期家庭健康協作層，讓長者、家人、藥師與臨床人員能共享可追溯的健康脈絡。

## 第一個市場切片

| 面向 | 已確認的選擇 |
| --- | --- |
| 市場 | 台灣 |
| 主要使用者 | 約 35-50 歲、具數位能力的成年子女 |
| 父母所在地 | 與子女不同、醫療資源相對充足的台灣城市 |
| 家庭結構 | 父母夫妻同住，生活大致能自理 |
| 就醫模式 | 在大醫院長期追蹤，並因臨時症狀前往小診所 |
| 溝通條件 | 父母曾因聽力困難而無法確認或轉述口頭醫囑 |
| 家庭協作 | 成年子女遠端協調，配偶提供現場觀察 |
| 現有管道 | LINE、電話，以及藥袋或藥品照片 |
| 決策權 | 長者保有最終健康與用藥決定權 |
| 信任來源 | 原看診醫師或藥師，其次為衛福部、健保署與食藥署等可辨識的政府來源 |

主要使用者、手機操作者、用藥管理者、健康決策者與受益者不一定是同一個人：

- 成年子女是主要的協調使用者。
- 長者是主要受益者、主動參與者，也是最終決策者。
- 配偶是現場觀察者與協助者，但不應被預設為用藥管理者。
- 醫師與藥師仍是臨床判斷的來源。

## 代表性的用藥溝通事件

1. 長者因新的不適症狀，自行到附近診所看診。
2. 家人無法確認長者是否向醫師說明既有慢性病與目前使用的藥物。
3. 長者帶藥回家，卻無法清楚轉述醫師的判斷、服用方式、預計療程，或新藥與既有治療的關係。
4. 如果覺得藥物沒有效果，長者可能在未經專業確認的情況下自行停藥。
5. 遠端家人透過 LINE 詢問、索取照片，再比對不同家人掌握的零碎資訊。
6. 診間的口頭脈絡已經消失，家人最終仍無法建立可信的共同事實。

這首先不是提醒失效，而是醫療溝通未能被保存、確認與交接。

## 現有替代方法及其失敗原因

- **LINE 詢問與電話：** 仍依賴長者當下聽清楚、記得並能準確轉述。
- **藥袋照片：** 可以看見調劑出的藥品，但無法保留醫師的判斷、注意事項與後續追蹤指示。
- **家人自行拼湊：** 不同家人持有不同片段，也缺少來源脈絡。
- **自行搜尋：** 可以取得一般藥物資訊，但無法還原這位病人的個別醫囑。
- **健保紀錄：** 是重要的背景資料，但無法完整呈現長者實際聽到、理解、服用、停止，或在健保處方以外使用的內容。

家庭缺少的是共同且可信的資訊來源，不是關心的意願。

## 實際用藥情境

作為動機來源的案例包括大醫院長期治療、小診所臨時處方，以及過去一段時間使用中藥的經驗。目前沒有自行購買保健食品的明確問題。

產品可以記錄據稱使用了什麼、何時開始或停止，以及同時期的症狀。若缺乏適當證據與專業判斷，產品不得推論藥物、傳統療法、食物或保健品造成病情改善或惡化。

## 信任、同意與家庭關係

- 長者的合作是必要條件；家人不應被預設為自動擁有資訊存取權。
- 分享應強化長者的自主權與成就感，而不是把長者視為被監控的資料來源。
- 家人可以觀察、整理、提問，並鼓勵進一步向專業人員確認，但不能暗中取代長者做決定。
- 當資訊可追溯至原看診醫師、藥師或具公信力的公共來源時，長者較可能接受。
- 未知、互相衝突或可能有風險的資訊，必須明確維持為不確定狀態，並轉介給合格的專業人員。

## 產品承諾與非目標

### 第一階段承諾

看診後，長者與遠端家人可以共同確認：

- 醫師傳達了什麼；
- 藥物應該如何使用；以及
- 哪些內容仍不確定或需要進一步詢問專業人員。

### 明確的非目標

第一階段產品不會：

- 診斷疾病；
- 開立處方，或建議改變藥物與劑量；
- 決定長者是否應開始或停止治療；
- 推論治療、食物與症狀之間未經證實的因果關係；
- 將 AI 產生的內容呈現為原始醫囑；
- 治療聽力損失；
- 試圖解決所有高齡者的 accessibility 問題；
- 將一般服藥提醒、全面交互作用檢查或完整慢性病管理作為核心產品承諾。

Challenge 仍要求具來源的藥物說明、結構化紀錄、可供照護者或臨床人員閱讀的摘要，以及安全升級。這些能力應服務醫療溝通與交接切入點，而不是各自成為無關的產品中心。

## 為什麼是 Hearing-First，而不是 Voice-First

創辦人最初關心的問題不是長者缺乏語音介面，而是口頭醫療資訊轉瞬即逝，可能從未被可靠地聽見、確認或轉述。

被否決的定位：

- **「聽障者用藥工具」：** 過度醫療化，也可能排除已有真實溝通困難，但沒有正式診斷或不認同自己是身心障礙者的長者。
- **「所有高齡者的 accessibility 工具」：** 範圍過廣；視覺、聽力、認知、手部操作、語言與識字能力造成不同問題，也需要不同調整方式。
- **「高齡者 Voice AI」：** 在聽力本身就是問題的一部分時，仍把音訊當作解答，也預設語音辨識能可靠處理口音、混合語言與非典型語音。

選定的定位：

> 讓已經遭遇聽力相關溝通失效的家庭，可以回顧、確認並分享口頭醫囑。

Voice、錄音、轉錄、文字、圖片或人工修正，都可能在未來支援這個成果，但本意圖文件不預先選定任何方式。最終設計必須容許辨識失敗，並保留資訊來源。

## 證據分類紀錄

### 創辦人經驗

- 一位家人接受長期醫院追蹤，同時也會因臨時症狀自行前往附近診所。
- 聽力困難使家人無法確認醫囑是否被聽見，也不知道相關病史是否曾向醫師說明。
- 遠端家人使用 LINE 與照片重建事件，仍然無法確認醫囑與實際用藥行為。
- 長者保有最終決策權，也較能接受可追溯至醫師、藥師或政府來源的資訊。
- 長者自願且持續分享，比完成一次技術操作更能代表成功。

這些觀察支持產品論點，但不能證明市場盛行率。

### 市場事實

- 台灣 2026 年常住人口統計顯示，65 歲以上人口占 19.2%，六都常住人口合計占 71.7%。這支持選擇明確的城市型第一市場，而不是籠統地描述「台灣長者」。[中華民國統計資訊網](https://www.stat.gov.tw/News_Content.aspx?n=3703&s=235805)
- 台灣健保保險對象可在特約醫院、診所與藥局間選擇。方便的多院所就醫，使跨提供者溝通成為需要驗證的重要流程。[健保署](https://www.nhi.gov.tw/en/cp-1065-d7cde-125-2.html)
- 健康存摺已提供跨院所的健康與用藥紀錄，因此產品論點著重理解、實際行為與資訊交接，而不是假設紀錄不存在。[健保署健康存摺](https://www.nhi.gov.tw/en/cp-562-2313c-22-2.html)
- 台灣用藥安全計畫將 65 歲以上、使用超過五種藥物且具有多重慢性病者列為高關懷對象。[衛福部](https://www.mohw.gov.tw/cp-3219-22662-1.html)
- 台灣以 ICOPE 為基礎的計畫，將聽力列為高齡者六項獨立能力之一。截至 2023 年 8 月所報告約 19.2 萬名受評估長者中，8.7% 的聽力篩檢結果異常；這是服務結果，不是全國盛行率。[衛福部](https://www.mohw.gov.tw/cp-6560-75997-1.html)
- 一項在台北兩個行政區進行的社區聽力研究發現，年齡相關聽力損失相當常見，但其地方性、自願參加樣本不應被泛化為全國盛行率。[台灣原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11743292/)
- WHO 指出，未處理的聽力損失會限制溝通，並可能造成社會孤立、孤獨與污名；支援方式除了聽覺輔具，也包括字幕與其他輔助科技。[WHO](https://www.who.int/news-room/fact-sheets/detail/deafness-and-hearing-loss)
- 台灣網站無障礙規範將電子文字視為可依需求轉換成視覺、聽覺、觸覺或混合呈現的資訊。這支持多模態設計，而不是只提供音訊。[數位發展部](https://accessibility.moda.gov.tw/Accessible/Guide/68)

### 尚未驗證的產品假設

- 其他相似的台灣成年子女也會把自己視為非正式的家庭健康協調者。
- 聽力造成的醫囑流失足以促使家庭持續使用產品。
- 當產品強化自主與家庭連結時，長者會自願持續分享資訊。
- 以成年子女為主要使用者，比僅服務長者的流程產生更高價值。
- 家庭會信任清楚區分原始資料、家庭觀察與 AI 協助的呈現方式。
- 產品流程可以自然地與 LINE 並存，而不必讓 LINE 本身成為產品。

## 訪談決策歷程

| 主題 | 決策 |
| --- | --- |
| 最初使用者 | 從預設長者為主要操作者，改為遠端成年子女是主要協調使用者 |
| 長者角色 | 主動參與者、受益者、同意權持有人與最終決策者 |
| 地理 | 選擇醫療資源充足的台灣城市；核心問題是資訊碎片化，而不是醫療資源稀缺 |
| Accessibility | 聽力相關的溝通失效是使用者切入點；accessibility 是設計原則 |
| 核心問題 | 口頭醫療脈絡流失，而不只是缺乏提醒或用藥紀錄 |
| 現有流程 | LINE、電話、藥品照片與零碎的家庭資訊重建 |
| 信任 | 專業醫療人員與可辨識的政府來源，優先於缺乏來源的家人或 AI 解讀 |
| 核心承諾 | 保存並交接醫師傳達的內容、藥物用法，以及尚待確認的問題 |
| 成功 | 正確的共同理解，加上長者自願且持續參與 |
| 安全 | 不診斷、不開立處方、不自主決定用藥，也不提出缺乏證據的因果主張 |
| 12 週方向 | 在 5-10 個高度相似的家庭中持續使用，且不形成監控關係 |
| 六個月方向 | 建立家庭長期健康協作與可供專業人員檢視的歷史 |

## 驗證計畫與缺口

- 目前已有一個作為動機來源的家庭，可以進行第一次 prototype 測試。
- 另一位高齡親屬可能適合作為 accessibility edge case，但尚不能視為第一市場的代表性使用者。
- 招募另外一至兩個高度符合以下條件的家庭：
  - 父母生活大致能自理；
  - 父母與成年子女分住不同地點；
  - 至少一位父母曾因聽力問題而無法確認或轉述醫囑；
  - 成年子女原本就參與健康資訊協調。
- 同時觀察成年子女與長者。只訪談成年子女，無法驗證長者的意願、尊嚴與持續分享。
- 記錄每位參與者理解、忽略、拒絕或修正了什麼，以及這些觀察如何改變 prototype。

目前最重要的未解風險，是創辦人的家庭經驗是否能泛化到其他高度相似的台灣家庭。

## 刻意留待 PRD 與 TDD 決定

本意圖文件不決定：

- 產品管道是 LINE、獨立應用程式、網站或其他介面；
- 資訊透過錄音、即時轉錄、手動輸入、文件或照片匯入，或其他方式取得；
- 第一版 prototype 支援哪些口語；
- 資料分享權限、同意流程、保存期限或撤回機制；
- 是否及如何整合健保、健康存摺、診所、藥局或醫院；
- 藥物參考資料來源與 grounding 架構；
- AI model、語音辨識門檻、修正流程或失敗處理；
- 詳細的照護者與臨床人員介面。

上述決策必須追溯到這份已確認的產品意圖、challenge 安全契約，以及下一輪真實使用者測試所取得的證據。
